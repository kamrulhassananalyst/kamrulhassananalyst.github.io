সবচেয়ে সহজ update method:

1. `kamrul-portfolio-premium-fix-update-only.zip` file Extract করুন।
2. Extract করলে এই ৩টি file পাবেন:
   - index.html
   - styles.css
   - script.js
3. GitHub repository খুলুন:
   https://github.com/kamrulhassananalyst/kamrulhassananalyst.github.io
4. `Add file` চাপুন।
5. `Upload files` চাপুন।
6. Extract করা ৩টি file একসঙ্গে GitHub upload box-এ drag and drop করুন।
7. একই নামের পুরোনো files replace হবে — এটি ঠিক আছে।
8. Commit message লিখুন:
   Premium mobile hero and portrait upgrade
9. `Commit directly to the main branch` selected রাখুন।
10. Green `Commit changes` button চাপুন।
11. `Actions` tab-এ latest `pages build and deployment` green check হওয়া পর্যন্ত অপেক্ষা করুন।
12. Final website খুলুন:
    https://kamrulhassananalyst.github.io/
13. পুরোনো design দেখালে mobile browser refresh করুন অথবা Incognito mode-এ খুলুন।
