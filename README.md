# Mohammad Kamrul Hassan Portfolio — Preview Build

This is a responsive static portfolio website built from the supplied resume and photograph.

## Open locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a new public GitHub repository, for example `kamrul-portfolio`.
2. Upload all files and the `assets` folder without changing the structure.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` branch and `/ (root)`, then save.
6. GitHub will provide a public link after deployment.
